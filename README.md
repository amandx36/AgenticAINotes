# Agentic AI Notes Repository

## Purpose
This repository is a personal learning workspace for Agentic AI, LangChain, LangGraph, LangSmith, and MCP concepts.
It contains conceptual notes, code examples, architecture diagrams, and experimental prototypes.

## Core Folders
- `LangChain/`: notes and examples for LangChain, chains, agents, tools, RAG, and structured output.
- `LangGraph/`: graph workflow concepts, memory, persistence, self-RAG, HITL, and LangSmith integration.
- `MCP/`: MCP protocol documentation, lifecycle notes, and a sample MCP server.
- `Ai_Agents/`: raw planning agent notes and early concept sketches.

## Key Documents
- `LangChain/INDEX_AND_STUDY_GUIDE.md`: study path for the LangChain material.
- `LangChain/AGENTS_AND_TOOLS_GUIDE.md`: detailed agent and tool design guide.
- `LangChain/RAG_DEEP_DIVE.md`: deep dive into retrieval-augmented generation.
- `LangGraph/Persistance.md`: persistence and checkpointing concepts for graph workflows.
- `MCP/Introduction.md`: MCP architecture and protocol overview.
- `REPO_ANALYSIS.md`: repository-wide analysis and improvement recommendations.

## How to Use
1. Start with `LangChain/INDEX_AND_STUDY_GUIDE.md` for structured learning.
2. Read `LangChain/AGENTS_AND_TOOLS_GUIDE.md` to understand agents and tools.
3. Read `LangChain/RAG_DEEP_DIVE.md` for retrieval and knowledge grounding.
4. Review `LangGraph/` notes for graph orchestration, persistence, and HITL.
5. Use `MCP/Introduction.md` and `MCP/StepsMakingMCP.md` to understand MCP server architecture.
