# Making MCP

## Popular MCP Server Implementations
The two most commonly referenced MCP server implementations are:
1. **FastMCP**
2. **MCP SDK / official MCP library**

## Notes
- FastMCP is often used for rapid prototyping and local development.
- The MCP SDK provides a more standard toolset for production-ready MCP services.

## Production Insight
Choose the implementation based on your needs: use FastMCP for quick experiments and the MCP SDK for robust client/server integration.
